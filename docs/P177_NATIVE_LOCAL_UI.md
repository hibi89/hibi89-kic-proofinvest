# KIC P177 native local UI (Windows 10 / Linux)

On the Windows machine with Python 3.11 installed, install the approved local UI dependency once with `python -m pip install -r requirements-ui.txt`, then run `KUODRA-Local.cmd` or `python -B -m scripts.local_ui_launcher --enable-local-review`. Open **http://127.0.0.1:18651** on the same machine. Ctrl+C stops the server; other processes using that port are never terminated.

The launcher intentionally binds **127.0.0.1, not 0.0.0.0**, enables Streamlit CSRF/CORS protections, disables static-file serving, restricts upload size and inherits only a small OS environment allowlist: no inherited KUODRA/vendor/LLM token or network opt-in reaches the child. `--enable-local-review` opts in only to uploading locally possessed operator-source files; no actual SEC HTTP retries, vendor API usage, uploaded original copies, trades or organizer submission are performed by the launcher. Streamlit and the UI may create normal local runtime preferences/caches, but this command does not intentionally modify original data.

For an automatic **real HTTP** smoke test that launches and then shuts down the app: `python -B -m scripts.local_ui_launcher --smoke --port 18651` (exit 0 means loopback Streamlit health + root HTML responded; not a guarantee of complete UI/Production function). GitHub Actions also runs this on Windows and Linux in addition to existing Chromium tests.
