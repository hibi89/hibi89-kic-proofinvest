## 2. 본선 목표 사용자 여정과 데이터 경계

**사용자 질의(단일 기업·분석 기간)** → 기업 식별·허용 데이터 권한 확인 → 공개 SEC/발행사 공시·허가된 시장/거시 데이터 또는 승인된 **로컬** 사내 문서·CSV·SQLite 수집 → 단일 버전형 canonical schema 정규화(issuer/entity, fiscal period, time available, unit, currency, access policy, SHA evidence) → 독립 Engine A/B/C → 조건부 다변량 AutoML/통계 분석 → Guard VERIFIED/CONFLICT/UNAVAILABLE/HOLD → 인간 검토 → 브라우저 대시보드·PDF/HTML 보고서.

- **Engine A:** 주가/벤치마크와 실적 괴리를 산술적·출처 기반으로 분석. 허가된 시장 데이터가 없으면 시장 지표 결과를 제공하지 않고 `UNAVAILABLE` 표기; 주가 상승의 원인을 확정하거나 버블을 수치로 단정하지 않는다.
- **Engine B:** 현금흐름·매출채권·재고·부채·공시 주석 간 불일치 후보를 검증한다. 이상 징후를 회계 부정 확정으로 표현하지 않는다.
- **Engine C:** 비교기업·산업 성장률의 기간/통화/단위를 맞춘 조건부 상대분석 및 근거를 표시한다. 자료 부족 시 `HOLD`.
- **Agent:** 사용자 요청을 이해해 **승인된 도구만** 계획·호출하고, 실패/불충분 근거는 실패로 드러낸다. 결정적 규칙 엔진을 LLM 성능으로 포장하지 않는다. 로컬 모델은 사용 허가와 실측 검증 후 선택형으로 통합.
- **AutoML:** 소유 `AI_AutoML_Analyst`의 적절한 sklearn 구성 요소만 선별해 로컬 재사용. 공개/비공개 동일 메타데이터 계약을 쓰되 PRIVATE 원문·추론 결과·프롬프트·쿼리를 외부 모델/공개 서버로 전달하지 않는다. 미래 정보 누출 차단, issuer/group/time held-out, baseline 비교, 다중 검정, calibration/Brier(해당될 때)로 실측; 근거 부족 시 `NO_TRAIN`.
- **사용자 통제:** 분석 후 출처 링크·증거 SHA·데이터 시점·누락 원인을 확인하고 내보낼 수 있어야 한다. 금융 투자 권고·자동 주문·계좌 접근은 범위 밖이다.

## 3. 데이터 공급·라이선스 전략 — Massive 회신 반영

2026-11-10 전후 사용자가 받은 Massive 영업 회신(대화 중 사용자 제공 화면)의 요지는: 개인 Free/Basic은 개인·비상업·비업무 분석에 한정되며, 타인에게 원천/파생 시장 데이터를 보여주는 공개 데모·제3자 제공에는 별도 Business 이용 권한이 필요하다. NDX 지수 관련 거래소 라이선스도 별도로 필요하다. **해커톤 특별 라이선스가 없고 현재 과금이 시작되지 않았다는 안내**를 받았다. 이메일 원본·보낸 사람의 개인정보는 공개 저장소에 게시하지 않는다.

이에 따라:
1. Massive Free/Individual 데이터를 공개 심사 데모의 실제 시장 피드로 사용하지 않는다. 데이터 키 보유는 시연/재배포 권한이 아니다.
2. **SEC/발행사 공시**를 핵심으로 사용하되, SEC 403/429 원천 접근 문제를 우회하지 않는다. 공식 파일 소유/출처 확인, 적법 재사용 조건을 별도로 점검한다. 실패하면 이미 확보한 합법적 파일 또는 적법한 **오프라인 공개 자료**로 제한한다.
3. DART는 국내 기업의 **별도** 후보 소스. KRX·나스닥 지수·FRED에 포함된 제3자 자료는 개별 권리 확인 후 사용한다. FRED API 제공 자체가 기초 지수 재배포권을 의미하지 않는다.
4. 권리 미확보 시장값은 `UNAVAILABLE`, 데모 합성값은 `SYNTHETIC_FIXTURE`로 명확히 표시한다. 실제 값처럼 보이게 렌더링하지 않는다.
5. 출시/시연 비용 **0원 목표**, 그러나 무료 호스팅·공식 API의 호출 한도/상업·공개 조건과 기관 인프라 승인 없이 0원 보장하지 않는다. 유료 API/비즈니스 플랜/외부 데이터 요청·전송은 사용자 사전 승인 대상.
