# KIC 기능 담당자·총괄 메시지 연결

총괄 브랜치: `lead/kic`. 세 기능 작업자는 각자의 역할 폴더에 최신화한다.

- [연구 메시지](https://github.com/hibi89/hibi89-kic-proofinvest/blob/feature/research/docs/roles/research/TO_KIC_LEAD.md)
- [검증 메시지](https://github.com/hibi89/hibi89-kic-proofinvest/blob/feature/verification/docs/roles/verification/TO_KIC_LEAD.md)
- [위험 메시지](https://github.com/hibi89/hibi89-kic-proofinvest/blob/feature/risk/docs/roles/risk/TO_KIC_LEAD.md)

**총괄 지시 전 필수:** 각 원격 브랜치 HEAD 확인, 메시지 3개 열람, 대기 건 대응, `docs/roles/lead/MESSAGE_REVIEW.md`에 검토·지시 기록을 갱신. 메시지 전송은 자동이 아니며, 작업자 커밋 + 총괄 확인으로 이루어진다.
