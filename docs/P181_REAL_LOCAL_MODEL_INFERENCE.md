# P181 — real local CPU model execution: one-time public CI proof

P179+P180 tested actual HTTP via a disposable *emulator*, which does not prove that any AI model has ever generated output. P181 runs a **genuine** free and public tiny model in a disposable public GitHub Actions Ubuntu runner, with only pre-existing explicitly **synthetic SEC/stock/NDX fixtures**.

Published model: [SmolLM2 135M Instruct Q4_K_M](https://ollama.com/library/smollm2:135m-instruct-q4_K_M), approx. 105 MB; upstream family [SmolLM2](https://huggingface.co/collections/HuggingFaceTB/smollm2-6723884218bcda64b34d7db9), Apache 2.0 license. Official Ollama container is pinned to a specific version and published release digest, not :latest. Model download is a public read from the model registry, not a push or data transfer of owner originals. The model is stored only in a 450-MB container tmpfs, without persistent mount. The container publishes an HTTP listener on **127.0.0.1:11435 only** inside the ephemeral GitHub runner. It uses capped CPU/memory/processes, no-new-privileges and cap-drop ALL; cleanup destroys container and tmpfs. GitHub Actions may consume compute bandwidth; this optional job runs only when a push commit message contains `[model-e2e]`, **never on every code commit**, and is capped to 10 minutes.

`python -B -m scripts.real_local_model_inference_smoke` asserts an actual Ollama `/api/generate` response with `done=true` and `eval_count > 0`, indicating positive generated tokens, **not just a mock server**. Then it feeds the existing P179 bounded redacted synthetic review pair with explicit local-model consent through the real model, and records whether strict human-only A/B/C schema accepted the output or failed closed. **Either way Guard HOLD remains, no advice and no trades.** Exact prompt/LLM text and any user/file bytes are never printed or published in CI output.

This genuine-model execution proof **does not** establish actual enterprise model quality, genuine first-party SEC provenance, legal NDX/peer rights, representative peers, user Windows 10 inference, real user input consent, investment advice accuracy, or public Production. P179 returns `model_inference_authenticated=false` and `ai_agent_executed=false` intentionally: the CI can verify its disposable container, while the actual customer local server may be an untrusted proxy and must be verified separately.

To reproduce on a fully controlled Linux Docker workstation with no secrets and sufficient free disk: `bash scripts/real_local_model_inference_ci.sh`. This uses Docker Hub and the official public model registry; **do not run** with user originals or unapproved account/secret access. Do not put any GitHub PAT/token in the environment.
