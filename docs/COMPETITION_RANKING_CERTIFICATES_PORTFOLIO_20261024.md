## 3. 포트폴리오 작성 원칙 및 증빙 우선순위

- **레벨 0 — 참가 준비:** GitHub 프로젝트/합성 데모만 존재. 참가 완료·공식 제출·순위가 아니다.
- **레벨 1 — 유효한 공식 제출:** 실제 팀/개인 본인 계정 **최종 접수 영수증/제출 내역 상태** 확보 후 'KIC AI 에이전트 공모전 예선 기획서 공식 제출' 기재 가능.
- **레벨 2 — 본선 진출:** 대회 측 공식 12팀 발표 및 본인 팀/계정 연결 증명 → '본선 진출(최종 12팀)' 기재 가능. **모집 전체 팀 수가 확인돼야 '상위 X%' 계산 가능**.
- **레벨 3 — 수상/공식 순위:** KIC 공식 수상 발표·세부 확정 순위표·수상자 계정 연결·인증서 등 실증 후 **검증된 등수와 분모**만 기재. 수상팀 6개=모든 참가자의 1~6등 공개를 보증하지 않음.
- **레벨 4 — 실제 기술 성과:** 코드 commit SHA, GitHub CI 결과, 합성/실제 API 검증 범위, 독립 데모 URL/동영상 및 직접 구현/AI 활용 방식 표시. 오프라인 합성 155 PASS != 실제 OpenDART 진위/Agent E2E/운영 서비스.
- 포트폴리오에 넣을 링크: **KIC 공식 공고, 본인 실제 접수증, 공식 진출/수상/순위 공지, 발급된 인증서(발급된 경우), 공개 가능한 README/아키텍처/데모와 역할·본인 기여도**. 민감정보/비공개 PDF 및 인증자료 원본은 Public GitHub에 게시 금지.
- 작성 예시(상태 달성 후만): **'국부펀드 KIC AI 에이전트 공모전 — ProofInvest / 본선 진출(공식 발표 링크) / 개인 참가 / Research·Verification·Risk / Python·Streamlit / 실제 검증 범위'**.
- **현재 실제 성과란:** DAKER 팀장/개인 최종 제출권한 미확인; 예선 공식 접수 **NOT_STARTED**, 본선 진출·수상·공식 등수·인증서 **미발생**. 내부 날짜별 29 DONE/3 BLOCKED/28 NOT_STARTED는 대회 순위나 제품 완성률이 아니다.
