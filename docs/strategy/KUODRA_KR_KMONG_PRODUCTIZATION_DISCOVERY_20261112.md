## 1. 검증 가능한 고객 가설과 시장순위
1. **국내 KOSPI/KOSDAQ 공시 검증**: DART 보고서·재무제표를 근거로 현금흐름, 매출/재고/매출채권, 분기/연간 변화를 자동 설명. 개인/리서치 담당자용. 직접 종목 매수·매도 추천 금지.
2. **국내 기업 재무·거래처 실사**: 사용 권한 있는 재무 파일과 공개 공시를 비교하여 거래처 재무 건전성, 실적 주장/현금흐름 불일치, 누락을 근거 링크로 설명. 소기업, 구매/영업/재무 실무자. 신용등급/부정행위 확정 판정 금지.

4. **민감 기관/기업 내부자료 로컬 검증**: 향후 온프레미스/B2B. 실 고객 IAM/OS egress·보안/접근 검증 전에는 판매 기능으로 홍보하지 않는다.

## 2. 기술 범위와 A/B/C 예시 (실서비스 성능 주장 아님)
- **A Market Reality:** 적법한 주가/지수 시계열이 있을 때 시장 대비 가격·변동성·기초체력 추이를 비교한다. 라이선스 없으면 A는 UNAVAILABLE; B/C를 계속한다. 정확한 '버블 확률'은 출력하지 않는다.
- **B Financial Integrity:** DART 재무 항목에서 영업이익 vs 영업현금, 매출 vs 채권, 재고 vs 매출, 부채·이자부담 등을 연결/별도·단위·기간·공개시점이 맞는 경우에만 계산한다. 의심 신호는 확인할 항목이지 분식회계 확정이 아니다.
- **C Industry Context:** 비교 가능한 동종 업체/산업 공식 지표를 같은 회계기간·통화·데이터 권리로 맞춰 상대적 변화를 설명. 충분한 비교군 없으면 HOLD/UNAVAILABLE.
- **ML/통계:** 원본 출처→기업ID·시점·단위 정규화→특징 구성→시점/기업 홀드아웃→Dummy baseline 비교→유의미한 설명 후보만 보고→Guard 확인→사람 최종판단. 자료가 적거나 누수/출처 불명 시 NO_TRAIN/HOLD. 과거 테스트 개수를 금융 수익률/예측 성능으로 혼동하지 않는다.
- **출력:** 기업명·기간·원본 근거/링크·공식/산식·비교 그래프·원인 후보·불확실성·가드 결과를 포함한 1~3p 고객 보고서와 CSV/HTML/PDF(실제 확인된 포맷부터).
