> **가격 기준/기록:** 2026-10-24 12:20:30 KST. KIC 전용 예산(다른 대회 비용과 분리).
> **결론:** 추가 **현금 지출 0원**을 기본 운영정책으로 한다. 기존 PC·인터넷·현재 구독료·전력·사람의 투입시간은 매몰/간접비로 보고 이 **신규 현금 지출** 산정에서 제외한다.
> **상태:** 예산 모델/검증된 공시 가격; **실제 결제·실 API 호출·배포·비용 발생 없음**. 무료 티어 가입 자격/쿼터는 실제 프로젝트 계정에서 아직 미확인.

## 2. 실제 분석당 모델 비용 시뮬레이션

권고는 **Research**에 텍스트 LLM 1회, **설명 보고서**에 LLM 1회; Verification·Risk의 숫자 계산은 **Python으로 결정론적** 수행. 예시 총 소비량은 분석 1건당 입력 8,000 토큰 + 출력 2,000 토큰(전체 호출 총합, 실제 계측 전 가정)이다.

| 시나리오 | Gemini 2.5 Flash-Lite | Gemini 2.5 Flash |
|---|---:|---:|
| **무료 티어 내** | $0 | $0 |
| **유료 전환 시 1건** | $0.0016 | $0.0074 |
| **유료 전환 시 100건** | $0.16 (약 210원) | $0.74 (약 980원) |
| **유료 전환 시 1,000건** | $1.60 (약 2,120원) | $7.40 (약 9,800원) |
| **유료 전환 시 10,000건** | $16.00 (약 21,200원) | $74.00 (약 98,000원) |

- 공식 2026 토큰 단가: Flash-Lite 입력 **$0.10/M**·출력 **$0.40/M**, Flash 입력 **$0.30/M**·출력 **$2.50/M**. 실제 특정 최신 모델·요금은 서비스 시점 재확인.
- 예시 환율은 2026-10-23 한국은행 ECOS 원/달러 **1 USD ≈ 1,324.6원**으로 반올림. 부가세·부가 도구·검색 그라운딩 추가비·캐시·멀티모달·재시도는 미포함. 같은 분석에 다중 Agent·긴 컨텍스트를 쓰면 비용 증가.
- **무료 티어가 한도 초과하면 응답 실패/지연 가능**, 유료 자동전환이라고 가정하지 말 것. Gemini RPD/RPM/TPM은 **프로젝트별로** 적용되어 2026년 계정·모델 상태에 따라 달라짐. 접속 후 Google AI Studio에 나타나는 실 할당량 확인이 필수.
- 무료 요청 데이터는 Google 제품 개선에 사용될 수 있어 **공개 공시/공개 산업자료**만 제공. 고객 비공개 투자 메모·영업비밀·개인정보 입력 금지. 민감 데이터를 다루려면 무료 티어 그대로 운영 불가하며 별도 개인정보/데이터처리 검토 및 사용자 승인 필요.

## 3. 실사용 품질 기준 0원 구성

```text
기업 검색 / 공개 산업 자료 (합법적 공개 소스)
       ↓
Gemini 무료 API (출처 있는 Research 설명)
       ↓
OpenDART 무료 API (공시 원본/기간/단위·CFS/OFS 검증)
       ↓
Python Decimal (수치 계산·중복·충돌 거절)
       ↓
Python Risk (검증된 수치만 사용, 설명 가능한 규칙)
       ↓
Gemini 무료 API (근거에 한정한 보고서 문장)
       ↓
SQLite / Supabase Free (원본/결과와 조회 분리, 중복 비용 통제)
       ↓
Streamlit Community Cloud Free (UI/실제 작동 데모)
       └─ Cloudflare Pages Static (검증된 JSON 스냅샷, 보조 링크)
```

**기능적으로 서로 다름**: Cloudflare 정적 스냅샷은 **실행 중인 Agent의 대체품 아님**. 본선 공식 필수 작동 데모 URL은 별도로 실제 기능을 검증해야 함. Streamlit 12h 수면/리소스 한도, Supabase 7일 무활동 pause에 주의. 시연 전 반드시 브라우저에서 URL 열고 새 분석 1건/근거 링크/확장 조회를 검증할 것.

## 4. 지출 방지 엔지니어링 통제

- **고정 지출 목표 = ₩0**. 사용자 최종 승인 없는 신규 결제/유료 API 키/선불 충전/업그레이드·유료 도메인 구매 금지.
- Gemini 무료 프로젝트와 무료 키만 사용, 계정의 유료 결제 연결 여부 확인. 월·일·호출 횟수·총 토큰 사용량을 UI 및 앱 로그에서 감시.
- 계정 한도 소진 시 **앱 자체에서 호출 차단, 저장 결과 재사용, 가능한 부분만 보고**, 근거 없는 생성 답변/무한 재시도 금지.
- 회사+사업연도+공시 보고서 버전으로 검증된 RAW/정규화/보고서 캐시 키 설정. 새로고침은 조회만; 같은 입력에서 계속 외부 요청 발생시키지 않음.
- 금융 원문·API 키·민감 내용을 공개 GitHub에 넣지 않음. Streamlit Secrets 등 호스팅 보안 저장소에 토큰 설정.
- OpenDART 권한·쿼터·Google Free RPD/개인정보 이용조건·Cloud 배포 약관은 실 사용 시 확인. **Gemini 무료 한도와 심사 기간 충분한 가용성을 현재 보장할 수 없음.**
- **Vercel Hobby $0**도 대안이지만 *개인·비상업적 사용*만 허용. 경연/향후 판매 서비스 용도와 충돌하는지 모르면 무단 사용하지 않음.
- 대회 규정상 무료·유료 API 모두 허용되나 데이터 출처·라이선스 기록 의무.

## 5. 0원 불가 시 예비 계획 (승인 전 지출 금지)

1. **정상**: 외부 결제 계정이 없는 무료 Gemini + 무료 OpenDART + 무료 Streamlit/Supabase → **0원**.
2. **품질상 유료 텍스트 모델 필요**: 먼저 무료 쿼터·캐시·모델 조합 최적화. 이후 사용자 승인 시에만 최대 **1만~3만원 일회성 예비비**를 *지출 가능 예산 상한 제안*으로 검토(결제 승인이나 충전 실행은 아님). 실제 모델 호출 수에 비례하며 얼마를 써야 하는지는 테스트 후 결정.
3. **24시간 가용성과 개인정보 보호 때문에 유료 운영 필수**: 무작정 무료 유지하지 말고 기능·시연 필수 여부를 평가한 뒤 유료 호스팅 **예: Vercel Pro 기본 $20/월(세금 별도)**, Supabase Pro **$25/월부터**를 별도 사용자 승인 안건으로 올린다. 두 유료 플랜은 **필수 비용 아님**.
4. **무료 수면·쿼터 문제를 피할 수 없고 유료 승인 없음**: 미검증 라이브 데모 성공을 주장하지 않고 검증된 합성/정적 근거·시연 플랜 B와 제출 규정 재검토. 본선 필수 작동 URL 요건은 실제 기능 검증이 필요하므로 '0원 유지'만으로 요건 충족했다고 하지 않는다.
