## 측정 단위 및 계산

1. **하루 100% = 해당 날짜 확정된 '당일 핵심 산출물'의 세부 검증 항목 100점**. 작업 시작 전에 해당 일자의 작업을 2~5개의 **증거 기반 완료 게이트**로 세분화하고 가중치를 정한다(합계 정확히 100점). 일반 기본형은 **사전검토 20점 / 구현·자료확보 45점 / 검증·테스트 25점 / 증거 및 인수인계 10점**. 사용자 계정·접수 작업은 별도 구체 게이트로 재분할할 수 있다.
2. **진척률 = (실제 증거로 충족한 게이트의 점수 합 ÷ 100점) × 100%**. 0·25·50 등 임의 체감치 금지. 게이트 미검증은 점수 0. 검증 불가/승인 필요는 `BLOCKED`로 표시하고 남은 점수를 그대로 남긴다. 100%에는 그날 필수 증거·테스트·문서 커밋/접수 영수증까지 포함되어야 하며 **가짜 완료 금지**.
3. **예상 잔여시간(순작업/보수 한도)은 완료율과 독립적으로 재산정**한다. 예시: 30%라 해서 남은 시간이 무조건 원래 예상의 70%인 것은 아님. 각 미완료 게이트에 대해 필요한 **남은 순작업 추정(h)**과 **오류/검수 예비(h)**를 따로 합산한다. 보고 형식: `남은 예상 순작업 Xh + 예비 Yh = 보수적 잔여 상한 Zh`. **확실히 끝났으면 0+0=0h**. 외부 권한/접속 같은 불명확한 조건은 `BLOCKED(추정 불확실)`로 밝혀 예산을 보증처럼 말하지 않는다.
4. **실제 소요시간(h)**은 시작/종료 시각이 관측되거나 신뢰할 기록이 있을 때만 기록. 측정하지 않았다면 `미계측`; 완료 %로 실제 시간을 역산하거나 작업자가 생성한 추정 시간을 실측으로 가장하지 않는다.
5. **선행 완료/추가 작업**은 원래 날짜의 분모에 억지로 넣지 않는다. 기존 일정의 다른 날 목표를 앞당겨 완료했다면 `선행 수행`으로 따로 기록하고, 원래 날짜에 재수행하지 않도록 해당 날짜 도래 전 일일 계획을 새 작업으로 **이력 남겨 재확정**한다. 이월된 작업은 다음 날짜의 분모에 사전 명시하고 이전 날 기록을 소급 조작하지 않는다.
6. **부분중단도 보고 의무**: 하루 35% `BLOCKED`, 순작업 예상 2h + 예비 3h = 5h 등 중단점을 그대로 기록. 반복 실패 2회·예측 기본의 2배 초과·일 배정 상한 초과 시 다음 3일 재산정/작업 분할·원인/차단/사용자 승인 사항을 남긴다.
