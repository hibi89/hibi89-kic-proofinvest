- **KIC 내부 제출 목표 11/10**은 전체 총괄 계획과 일치. PayPal 내부 11/11, 공식 11/13 05:00, UGREEN 내부 11/14, 공식 11/16 16:45를 침범하지 않도록 KIC 예선 웹 풀스택 배포는 강제 마일스톤으로 잡지 않는다.
- KIC **당일 배당 제안**: 10/25~31 PDF 1~2h + 계약/테스트 1~2h, 11/1~5 PDF 2~3h + 최소 기술 검증 0~1h, 11/6~10 PDF/제출 1~2h. 사용자 직접 작업은 공식 제출 화면/접근권한 확인에 한정. 시간은 AI/사용자 가용량 미확인 가정값으로 강제 일과가 아님.
- 실 API 토큰·키는 공개 GitHub 금지. OpenDART 실제 호출/외부 유료 호출/접근 정책·아키텍처 변경은 사전 사용자 승인. 공동 사용량·비용·서비스 상한 검토.
- 일정상 지연 시: **10/31까지 스키마 미승인 또는 실 API 불가** → 합성 기반 정직한 기획서/본선 실행 계획으로 전환, 인증 우회·근거 없는 실증 주장 금지. **11/08 PDF 미완성** → 추가 기능 개발을 동결하고 공식 템플릿 충족·최종 제출 확보에 집중.
- 검증 가능한 완결 기준: GitHub 원격 커밋+CI는 코드/문서, 실 OpenDART/API는 별도, 기획서 제출은 DAKER 팀장 계정의 **'제출 완료' 상태**로 각각 확인. 3개 모두 혼동 금지.

## 8. 사용자/통합 총괄 결정 대기
