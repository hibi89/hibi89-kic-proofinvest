## 1. 승부 전략 — 변경하면 안 되는 기준

**기획서 중심이되 구현 증거를 포함한다.** 10페이지 예선 PDF를 가장 먼저 제출하고, KIC 투자·금융 업무에서 실현 가능한 3기능 AI Agent를 보여준다.

- 제품: **ProofInvest — 출처와 검증 상태를 추적하는 투자 리서치 AI Agent**.
- 핵심 차별화: **AI가 만든 주장도 검증의 대상**으로 삼는다. OpenDART 등 허용된 원문과 대조하고 **검증 실패를 숨기지 않는 Agent**.
- 고정한 세 기능: **Research → Verification → Risk → 근거 보고서**. 일반 금융정보 요약 챗봇이 아닌 Agent의 목적 이해·도구 선택/호출·검증·결과 생성 루프를 명시.
- 실증 요구: **(A) 실제 기업 공시 수치 1건 이상을 출처·기준일·CFS/OFS·통화·단위와 함께 검산**, **(B) 의도적으로 틀린 매출 성장률 주장을 conflict로 판정**, **(C) 근거가 없으면 unavailable로 계산/위험판단 보류**, **(D) 입력부터 보고서까지 재현 가능한 도구 흐름**. A는 OpenDART 사용 조건/인증/사용자 승인 이후 진행; 실패 시 문서에 미검증으로 표시.
- Verification의 숫자 계산은 `Decimal` 등 결정론적 Python. LLM은 조사/설명에만 사용하고 확인하지 않은 숫자를 생성하지 않음.
- **무료 우선**: OpenDART 무료 데이터 + 허용된 공개 자료 + Gemini 무료 티어(공개 자료만) + Python/SQLite + Streamlit 무료 + GitHub Public Actions. 사용 한도·휴면·개인정보 조건 검증. 영구/24시간 가용성을 무료 서비스가 보장한다는 주장은 금지.
- **투자권유·매매 자동화 제외**. 논란 있는 수치나 모호한 회계계정을 임의 보정하지 않음.
- **제출 우선순위**: 공식 양식 10쪽 내 필수 7요소, 명확한 차별화, 실현성 근거, 최종 접수 확인. 증거 없는 개발 완료 표현 금지.
