- 사용자의 기존 Library 비공개 동결 PDF를 **읽기 전용 텍스트**로 확인. **10쪽**이며 필수 구성 7개 영역이 존재한다. 디자인/글꼴 시각 QA는 이전 기록에만 근거; 이번 검사에서 새 브라우저/실제 제출 페이지·렌더링을 검증한 것은 아님.
- 강점: 한 가지 금융 업무상의 검증 문제, 세 단계 Research→Verification→Risk, 실패 시 보류하는 출력 계약, 단계별 MVP 범위와 미검증 범위 공개.
- 비교적 약한 심사 설득 영역: **(a) Agent 자율성/계획 변경·도구 선택의 구체적 시연 근거**, **(b) 기존 리서치/자동검산 도구와의 비교 우위 증명**, **(c) 처리시간 절감의 실측값**. 이는 사전 상대평가가 아니라 향후 질의응답·프로토타입 리스크를 찾은 내부 검토이며 공식 심사 점수나 감점을 예측하지 않는다.
- DAKER 커뮤니티에 명시된 전문가 100점 구성: 문제 정의/주제 적합성 **20**, Agent 구성/설계 **25**, 차별성/창의성 **20**, 실현가능성 **20**, 활용성/확장성 **15**. 관련 설명 https://daker.ai/community/kic-ai-agent-proposal-role-tool-flow-design . 특히 Agent 설계+차별성 합계 **45점**은 본선 코어에 집중해야 할 영역으로 분류한다.
